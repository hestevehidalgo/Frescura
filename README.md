# Frescura

"Saca una foto a tu boleta y nunca más botes comida sin darte cuenta."

App para iOS y Android que lee boletas de supermercado chilenas, estima cuándo vence cada alimento,
avisa a tiempo y sugiere recetas con lo que está por vencer.
